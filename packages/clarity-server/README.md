# Skalpl Clarity Server (`clarity-server`)

Whitelabel backend, ingestion collector, and heatmap API for the Skalpl ecosystem, powered by the open-source Microsoft Clarity engine.

## 🚀 Features

- **100% Strict TypeScript**: All data models, database interfaces, API requests, and visualization responses are strongly typed.
- **Native Multi-Tenancy**: Built-in project/site isolation with domain allowlisting to prevent spam and data leakage.
- **High-Throughput Ingestion**: Returns `204 No Content` immediately. Decodes and processes telemetry asynchronously.
- **Zero-Overhead Clustering**: Delivers pre-aggregated `Activity` and `ScrollMapInfo` payloads designed for GPU-accelerated client-side canvas rendering via `clarity-visualize`.
- **SDK Delivery**: Serves the compiled `tracker.js` bundle directly with browser caching.

## 🛠️ API Contracts

### 1. Telemetry Ingestion (Visitor Browser)
- **`POST /api/v1/collect`**
  - **Headers**: `Content-Type: text/plain` (or `application/json`), `Origin: https://client-domain.com`
  - **Body**: Raw string payload generated by `clarity-js`
  - **Response**: `204 No Content`

### 2. Multi-Tenant Project Management
- **`POST /api/v1/projects`**
  - **Body**:
    ```json
    {
      "id": "skalpl_store_alpha",
      "name": "Skalpl Store Alpha",
      "allowedDomains": ["store-alpha.skalpl.com"]
    }
    ```
  - **Response**: `201 Created`

### 3. Heatmap Data (Skalpl Dashboard)
- **`GET /api/v1/heatmaps/click?projectId=...&pageUrl=...&device=desktop&from=...&to=...`**
  - Returns: `HeatmapClickResponse` (`activity: Activity` array of `{ hash, selector, totalclicks, x, y, clicks, points }`).
- **`GET /api/v1/heatmaps/scroll?projectId=...&pageUrl=...&device=desktop`**
  - Returns: `HeatmapScrollResponse` (`scrollMap: ScrollMapInfo[]` with percentage distribution).
- **`GET /api/v1/heatmaps/snapshot?projectId=...&pageUrl=...&device=desktop`**
  - Returns: `PageSnapshotResponse` containing the raw Discover DOM payload to pass into `visualizer.html()`.

### 4. SDK Serving
- **`GET /tracker.js`**
  - Serves the minified `clarity.min.js` tracking bundle.
